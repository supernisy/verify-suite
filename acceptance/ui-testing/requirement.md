# 需求：verify-suite 通用 UI 测试能力（general-ui-testing）

把"大模型可视化 → 序列化 → UI 交互"链路提炼成可迁移的 skill，让任意 AI 套任意 UI
（浏览器 / 原生 App / 移动端）都能复现稳定的"理解 + 操作 + 验证"结果。

- 感知以 AX 树为主、截图补位（AX 拿不到的字段才截图，标 medium）。
- 交互支持观察 / 驱动 / 多步编排三类模式。
- 需求通过 OpenSpec 锁死、验收通过 spec gate 契约定义"什么算对"。
- 每个输出字段带来源与置信度（`ax-tree=high` / `screenshot=medium`），可被第三方复核。
- 完整性必须断言：去重 + 已知总数比对；空/缺 = 执行错误，不是"完成"。
- 安全边界沿用业界标准人审边界（登录/支付/删除/发消息一律停下问）。

与既有"前端还原度校验"能力的关系：判定层（契约 / 指纹 / 证据 / 完整性）复用，
驱动层新增 `adapters/web-cdp/`（主，浏览器）+ `adapters/ax-native/`（扩展，原生 App）。
