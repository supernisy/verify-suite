# OpenSpec Spec 模板 — 通用 UI 测试需求

> **用法**：复制本模板到 `openspec/specs/<capability>/spec.md`，按 `<...>` 占位替换。
> **原则**：写"做什么 + 不做什么"；scope 显式；场景用 Given / When / Then；需求锁死后不做范围蔓延。

---

## <Capability 名称>

### 概述
<一句话说明要测试的 UI 目标与目的，例如"从某原生 App 的聊天记录窗口抽取结构化消息列表">

### 适用范围（做什么 / 不做什么）
- ✅ 做：<列出本需求覆盖的 UI 测试行为，例如"抽取每条消息的说话人 / 时间 / 正文">
- ❌ 不做：<显式排除，例如"不截图、不驱动写操作、不处理图片">

### 目标类型与选型（Phase 0）
- 目标类型：<原生 App | Web | 移动端 | 纯视觉>
- 首选工具：<AX 树 | CDP | 无障碍桥 | 截图+模型>
- 理由：<为什么选它，例如"原生桌面 App，AX 结构化、确定性、直接拿文本">

### Requirements

#### Requirement: <需求标题>
<自然语言描述系统 SHALL 做什么，例如"系统 SHALL 从记录窗口枚举全部消息并保留顺序">

**Scenario: <场景名 — 正常路径>**
- **Given** <前置 UI 状态，例如"记录窗口已打开、可见 N 条消息">
- **When** <触发动作 / 抽取请求，例如"执行序列化枚举遍">
- **Then** <可验证结果 + 完整性断言，例如"输出 N 条去重消息，首尾时间戳落在已知区间">

**Scenario: <场景名 — 边界 / 降级>**
- **Given** <例如"某字段 AX 树不暴露（如头像）">
- **When** <例如"进入富化遍">
- **Then** <例如"走截图补位，confidence=medium，并记入 degradation 账本，不静默丢弃">

### 验收口径（对接 spec gate）
- 字段清单：<要抽取的字段>
- 完整性：<条数 / 去重 / 首尾时间跨度 / 与已知总数比对>
- 证据等级：`ax-tree=high`，`screenshot=medium`
- 安全边界：<是否触及人审边界（登录 / 支付 / 删除 / 发消息）；触及则停下问人>
